# Weather App

A simple Python weather application that allows users to check weather information and save search history.

## Features

- Search weather by city
- Save search history
- JSON data storage
- Simple command-line interface

## Technologies Used

- Python
- JSON
- API requests

## Project Structure

weather-app/

├── main.py
├── weather_service.py

└── README.md
